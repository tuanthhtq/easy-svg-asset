# Project structure

easy-svg-asset is a local-first Electron app. `src/main/index.ts` owns the active folder, `.easy-svg-asset/project.json`, recent-folder storage, SVG file IO, project-scoped Snap/Grid and active AI style preset settings, global Library IO, safe SVG validation, PNG export, global app settings, AI style preset IPC, and OpenAI IPC. `src/main/settings.ts` stores global Auto-save and OpenAI URL/model settings in Electron user data and encrypts the API secret with `safeStorage`; `src/main/ai-style-presets.ts` stores global style rules and bounded reference images under Electron user data; `src/main/openai.ts` calls the OpenAI Responses API and converts function calls into validated AI commands, including active style rules and references. `src/main/ai-logger.ts` writes full AI request, API, response, and error events to per-launch JSON files under Electron user data `ai-logs`, retains the newest five files, and redacts the API key. `src/preload` exposes the typed IPC boundary. `src/renderer/src/App.tsx` coordinates project, document, Library, global settings, style presets, palette state, AI preview/apply, and IPC state. `src/renderer/src/editor` owns Fabric canvas behavior, stable object IDs, named groups, AI scene context, AI shape execution, collision validation, and history, while `src/renderer/src/components` contains the workspace UI, Settings dialog, style preset manager, and collapsible canvas AI box. `src/shared` contains IPC types, AI command schemas/validation, manifest handling, and SVG validation. Project SVG files remain ordinary files in the selected folder; the manifest stores identity, active document, Snap/Grid settings, and the selected global style preset ID. Global shapes, app settings, style presets, and style reference images live under Electron user data; palettes remain renderer-local presets.

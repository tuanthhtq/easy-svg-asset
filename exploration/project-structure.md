# Project structure

easy-svg-asset is a local-first Electron app. `src/main/index.ts` owns the active folder, `.easy-svg-asset/project.json`, recent-folder storage, SVG file IO, project-scoped Snap/Grid settings, global Library IO, safe SVG validation, and PNG export. `src/preload` exposes the typed IPC boundary. `src/renderer/src/App.tsx` coordinates project, document, Library, global Auto-save delay, and IPC state. `src/renderer/src/editor` owns Fabric canvas behavior and history, while `src/renderer/src/components` contains the workspace UI. `src/shared` contains IPC types, manifest handling, and SVG validation. Project SVG files remain ordinary files in the selected folder; the manifest stores identity, active document, and Snap/Grid settings. Global shapes live under Electron user data; Auto-save delay lives in renderer local storage.

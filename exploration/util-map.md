# Utilities

`src/shared/project.ts` creates or validates `.easy-svg-asset/project.json` and atomically records the active document. `src/shared/ai.ts` validates OpenAI tool arguments, scene bounds, object IDs, active-palette usage, current stroke/radius style, collision rules, and scene-aware commands. `src/shared/svg.ts` rejects oversized SVG and active content. `src/main/settings.ts` validates global settings and encrypts the OpenAI secret with Electron `safeStorage`; `src/main/openai.ts` handles OpenAI Responses API requests, image input, and function-call parsing. `src/renderer/src/editor/history.ts` provides branch-aware undo/redo state, and `useCanvasEditor.ts` contains Fabric canvas operations, stable object IDs, named-group SVG metadata, scene snapshots, and atomic AI command application. Main-process path checks require regular files inside the active folder or global Library.

# Component map

`App` opens folders, coordinates document and Library IO, loads global settings, owns renderer palette state, loads global AI style presets, debounces SVG auto-save, validates AI proposals, applies palette changes, and coordinates the AI box. `useCanvasEditor` owns the Fabric canvas viewport, infinite pan/zoom, layer-focused viewport centering, anchor-based closed pen paths, drag-created shapes, uniform strokes, grid snapping for movement, size, and rectangle radius, live transform sync, document sizing, keyboard editing, draggable rectangle radius controls, selection transforms, context-menu layer order, Figma-style group drill-in, permanent flattened groups, named AI asset groups, stable object IDs, compact AI scene snapshots with current drawing settings, temporary AI canvas previews, atomic AI approval, undo/redo, nullable Fill/Stroke defaults, and transparent PNG/SVG export. AI preview objects are excluded from scenes, layers, saving, export, and history until approval. AI-created game assets use only the active palette and must match the current stroke width and rectangle radius; multi-part assets are limited to eight essential shapes. Resize snapping respects the active Fabric control: side handles change one axis, corner handles change both. Fabric custom properties and SVG metadata preserve layer names and object IDs. `Inspector` receives the lifted renderer-local palette presets, applies colors or `None` to the active Fill or Stroke target, exposes synced X/Y/W/H, radius, and stroke-width fields, uses inline preset name forms, and exposes color editing only in palette edit mode through middle-click or a context menu. Stroke width syncs from the selection and becomes the default for newly drawn shapes. `EditorStage` renders Snap and Grid controls above the infinite workspace and hosts the collapsible AI box. `AppButton` is the shared renderer button wrapper, defaulting to `type="button"` and the app's base button styling while preserving component-specific classes. `Settings` edits global Auto-save, OpenAI configuration, and global AI style presets with reference images; `AiBox` sends every palette ID, name, and color list with the active palette ID, lets the user retarget palette updates, asks whether updates replace, append, or replace checked colors, selects a project-linked style preset, sends its rules and references, accepts text or pasted images, previews generated palette names, swatches, and hex values before approval, renders shape proposals on the canvas, and supports regenerate, reject, or approve. `Welcome`, `ToolRail`, `ProjectPanel`, `EditorStage`, and `Inspector` forward editor actions, including inline layer rename. The tool rail and project panel fill the desktop window height; below 940px the inspector becomes a selection-only overlay.

# Component map

`App` opens folders, coordinates document and Library IO, loads global settings, owns renderer palette state, debounces SVG auto-save, validates AI proposals, applies palette changes, and coordinates the AI box. `useCanvasEditor` owns the Fabric canvas viewport, infinite pan/zoom, layer-focused viewport centering, anchor-based closed pen paths, drag-created shapes, uniform strokes, grid snapping for movement, size, and rectangle radius, live transform sync, document sizing, keyboard editing, draggable rectangle radius controls, selection transforms, context-menu layer order, grouping, permanent flattened groups, named AI asset groups, stable object IDs, AI scene snapshots, AI primitive/pen creation, atomic AI application, undo/redo, nullable Fill/Stroke defaults, and transparent PNG/SVG export. Resize snapping respects the active Fabric control: side handles change one axis, corner handles change both. Fabric custom properties and SVG metadata preserve layer names and object IDs. `Inspector` receives the lifted renderer-local palette presets, applies colors or `None` to the active Fill or Stroke target, exposes synced X/Y/W/H, radius, and stroke-width fields, uses inline preset name forms, and exposes color editing only in palette edit mode through middle-click or a context menu. Stroke width syncs from the selection and becomes the default for newly drawn shapes. `EditorStage` renders Snap and Grid controls above the infinite workspace and hosts the collapsible AI box. `Settings` edits global Auto-save and OpenAI configuration; `AiBox` accepts text or pasted images and requires review before Apply. `Welcome`, `ToolRail`, `ProjectPanel`, `EditorStage`, and `Inspector` forward editor actions, including inline layer rename. The tool rail and project panel fill the desktop window height; below 940px the inspector becomes a selection-only overlay.

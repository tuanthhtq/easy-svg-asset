# Component map

`App` opens folders, coordinates document and Library IO, and debounces SVG auto-save. `useCanvasEditor` owns the Fabric canvas viewport, infinite pan/zoom, layer-focused viewport centering, anchor-based closed pen paths, drag-created shapes, uniform strokes, grid snapping for movement, size, and rectangle radius, live transform sync, document sizing, keyboard editing, draggable rectangle radius controls, selection transforms, context-menu layer order, grouping, permanent flattened groups, undo/redo, nullable Fill/Stroke defaults, and transparent PNG/SVG export. Fabric custom properties preserve layer names and flattened IDs through history. `Inspector` stores user palette presets in renderer local storage, applies colors or `None` to the active Fill or Stroke target, uses inline preset name forms, and exposes color editing only in palette edit mode through middle-click or a context menu. `EditorStage` renders Snap, Grid, and Auto-save controls above the infinite workspace. `Welcome`, `ToolRail`, `ProjectPanel`, `EditorStage`, and `Inspector` forward editor actions, including inline layer rename. The tool rail and project panel fill the desktop window height; below 940px the inspector becomes a selection-only overlay.
